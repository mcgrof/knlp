Quantization · failure mechanisms

FP8 KV-Cache Failure Atlas

R&D completeWhy symmetric FP8 can fail

Why does symmetric KV quantization catastrophically break some models? The atlas traces FP8 key failures to learned key bias and incompatible subspace distributions, with controls across model families.

FindingKey and value precision need separate qualification. Retaining BF16 keys is the conservative fallback for fragile models; robust models can still use symmetric FP8.

Learned prefixes · asymmetric precision

Asymmetric Cartridge KV

R&D completePositive finding · shared cartridges

Keep trained cartridge keys in BF16 and compress values to FP8. On the tested Qwen3-8B cartridges, K16/V8 cuts raw KV bytes by 25% with about 0.03% higher paired evaluation loss.

Serving resultThe fused shared-cartridge path records modest throughput and latency gains over BF16 injection in the controlled runs. Broader deployment qualification remains open.
