AI R&D · Fisher information

One signal.
Several research questions.

The diagonal Fisher Information Matrix (FIM) uses expected squared gradients as a sensitivity signal. These experiments explore how that signal can guide pruning, precision and placement, including estimates drawn from Adam’s second-moment state.

This work helped open the path to KV quantization and asymmetric key/value precision. An important negative finding changed the approach: the Fisher signals we tested did not significantly predict which layers would suffer from KV quantization. We turned to measuring that damage directly.

What changed the direction

From Fisher signals to K/V precision

A useful research path can start with a predictor that does not hold. These results concern KV-cache sensitivity; weight precision is a separate experiment.

Test the predictor

Fisher ranking did not predict KV damage

On Qwen2.5-7B and Mistral-7B, the measured Fisher ranking had no significant correlation with the perplexity change from quantizing one layer’s KV cache: Spearman ρ = −0.19 (p = 0.333) and 0.12 (p = 0.510). A follow-up cross-layer interaction signal also failed to predict sensitivity.

These tests did not establish a useful predictor. They do not prove that every Fisher-based method must fail.

Find where precision is lost

Direct quantization tests exposed a strong key/value asymmetry on fragile models. The later FP8 failure atlas traced specific failures to learned key bias and incompatible subspace distributions, rather than a universal model-size rule.

Qualify asymmetric precision

The practical continuation is to qualify keys and values independently, preserve sensitive keys, and compress values where the measured quality allows it. That work now spans serving kernels, LMCache storage and trained cartridges.
