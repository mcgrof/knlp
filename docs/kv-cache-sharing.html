Cross-model KV-cache sharing · evidence map · October 2026

Three tested ways to repair a cache after a model change.

KV-Lingo translates retained cache spans. DroidSpeak recomputes one receiver-layer interval. Modified Mixture-of-Translators (MoT) injects translated K/V into a source-selected reduced-key replay. All three try to avoid full receiver prefill, but they use different model pairs, data, controls, and quality rules.

What we learnedCross-model cache reuse can work, but only when the receiver repairs the cache carefully. DroidSpeak worked for one closely related Mistral pair by rebuilding 4 of 32 layers. Our Qwen3-4B/8B KV-Lingo checkpoints did not keep answer quality when either model could start. The modified-MoT translator helped on NewsQA, but its reduced-key replay still caused most of the quality loss. LMCache can move a cache between servers; it cannot make an incompatible cache safe to use.

Each effort answers a different question

A KV cache stores the attention keys and values for prior tokens. Ordinary reuse requires the same model weights and cache layout. Cross-model reuse needs a method to repair the representation mismatch.

Effort 1 · KV-Lingo

Translate each model's missing cache spans

Learn separate linear key and value maps for corresponding receiver layers. Keep one cache line per model. When a model returns, translate only the conversation spans that it did not produce itself.

Tested here: repeated ten-turn switching between Qwen3-4B and Qwen3-8B on 32 CoQA (Conversational Question Answering) conversations.

UNRESTRICTED USE NOT QUALIFIED

Read the full KV-Lingo result →

Effort 2 · DroidSpeak

Reuse most layers and recompute a receiver window

Profile one contiguous receiver-layer interval. Reuse sender KV outside it, inject a transition embedding at its start, and compute native receiver KV inside it.

Tested here: one handoff between two Mistral-7B adapters, with 50 profile and 50 disjoint held-out HotpotQA multi-hop question-answering records.

MECHANISM QUALITY QUALIFIED

Read the full DroidSpeak result →

Effort 3 · modified MoT

Translate K/V inside selected-key replay

Use source attention to select at most 128 prior keys. Replay the receiver with exact bottom layers and inject translated K/V at four configured target layers.

Tested here: one frozen GPT-2 to GPT-2-medium checkpoint on 500 items from five question-answering tasks, with four inference-only control arms.

MECHANISM SIGNAL; RECIPE NOT QUALIFIED

The three methods repair different state

KV-Lingo

Repair retained spans

Source K/V passes through learned layer-specific maps. Each model keeps a cache line with native and translated spans.

DroidSpeak

Repair a layer interval

Sender K/V stays outside a profiled interval. The receiver recomputes native state inside that interval.

Modified MoT

Repair a reduced-key replay

Source attention selects keys. Learned translators inject receiver-width K/V into that selected replay trajectory.

What the current evidence says

Token F1 measures normalized word overlap with the reference answer. Each study compares its treatment only with its own matched controls.

KV-Lingo outcome
0 / 4

Forward/reverse checkpoint pairs passed the full rule across both starting models and both native references.

All eight 4B-start comparisons failed at least one gate. The 8B-first signal is a narrower development result, not a qualified deployment.

DroidSpeak outcome
4 / 32 layers

The selected receiver interval scored 0.3149 held-out F1 versus 0.2887 for full receiver prefill and a required floor of 0.2742.

Direct cache reuse scored 0.2263. Some receiver recomputation was necessary.

Modified MoT outcome
+2.68 F1

On NewsQA, translated selected replay scored 11.11% versus 8.43% without injection. The paired 95% interval was +0.52 to +4.82 points.

Exact native scored 19.67%. Translation recovered about 24% of the observed replay-to-native gap; it did not qualify the recipe.

SUPPORTED

Cross-model cache repair can preserve quality for the tested same-base DroidSpeak adapter pair. In modified MoT, learned translation also adds measurable value inside one reduced-key cohort.

NOT YET SUPPORTED

No study here proves arbitrary cross-family reuse, a universal checkpoint, production reliability, or an end-to-end cost saving. Modified MoT does not pass an overall quality gate.

ARTIFACT BOUNDARY

The public code and source pins are available. The exact tested KV-Lingo and modified-MoT checkpoint tensors are not published. DroidSpeak produces configuration, not trained weights.

Modified MoT: what the four-arm attribution isolated

The frozen run did not train or profile. It kept one GPT-2 to GPT-2-medium checkpoint, five 100-item task cohorts, one source-derived selection procedure, Top-S=128, two exact bottom layers, greedy decoding, and a 64-token output cap. Each item ran four arms.

TRANSLATOR SIGNAL

NewsQA always uses reduced keys. T beat R by 2.68 F1 points, and the document-cluster interval excludes zero. This is evidence that the frozen translator adds useful information inside that path.

DOMINANT OBSERVED LOSS

R was 11.24 points below N on NewsQA. T recovered about 24% of that gap and remained 8.56 points below N. The fixed replay path and cache trajectory dominate the observed deficit.

FULL-KEY CONTROL

R and N produced identical tokens on all 189 items whose contexts fit inside Top-S=128. Divergence starts when the path actually removes keys.

Interpretation limit: the result does not separate source-guided ranking from the later selected-attention trajectory. The configured layer-23 injection has no downstream prefix-cache layer, so only the first three injection sites can change the returned cache. The other T−R intervals cross zero. SQuAD has only four context clusters, and several classification cohorts have weak or invalid-answer baselines. No speed or memory claim follows.

Could DroidSpeak improve KV-Lingo?

Yes as a research design, but not as a drop-in patch for the current Qwen3-4B/8B pair. DroidSpeak offers a way to spend native receiver compute where translation or selected replay is most damaging. The modified-MoT attribution strengthens this rationale because replay, not missing translated injection alone, caused most of its measured NewsQA gap.

Profile translated-cache quality across candidate receiver-layer intervals. Treat full translation as the zero-recompute control and full receiver prefill as the correctness control.
For each interval, translate the boundary hidden state into the receiver width, recompute native receiver KV inside the interval, and use translated KV outside it.
Select the smallest interval that passes untouched quality data, then measure transfer, translation, recomputation, storage, and time to first token end to end.
WHY IT COULD HELP

KV-Lingo shows a large first 4B→8B handoff deficit. Modified MoT shows that useful translated K/V cannot by itself repair a weak reduced-key trajectory. Local native recomputation could reset that state before decode.

WHY IT IS NEW WORK

The current DroidSpeak path assumes equal hidden shapes and aligned layers. Qwen3-4B and Qwen3-8B do not satisfy that contract. A hybrid needs a trained hidden-state bridge, explicit layer alignment, and tests that the recomputed interval can consume translated boundary state safely.

Most credible first test: start with two adapters on one base architecture, where DroidSpeak already works, and add KV translation outside the selected interval only if direct reuse remains weak. Test a cross-width Qwen3 pair after the same-shape hybrid passes exact controls.

LMCache is transport, not representation repair

LMCache can share a compatible cache between serving processes. Our control retrieved 7,168 same-model cached tokens and produced an identical completion. Cross-model use still needs translation, partial recomputation, or selected replay in the receiver runtime.

Transport

LMCache

Names, stores, moves, and retrieves compatible KV data across processes or nodes.

Representation repair

KV-Lingo

Maps cached keys and values from one model representation to another.

Representation repair

DroidSpeak

Reuses compatible sender layers and rebuilds one interval with receiver compute.

Representation + replay

Modified MoT

Stores source state and a selection ledger, then runs receiver replay with translated injections.

Production composition: LMCache could carry stored tensors and transition state. The serving engine must still enforce model-pair, token-position, selection-ledger, and replay compatibility before it runs a cross-model path.

Reproduce the public modified-MoT path

The public repositories contain the modified source chain, KNLP wrapper, defconfigs, controls, and result evaluator. Use Python 3.10 or 3.11 with the pinned MoT requirements. Keep model snapshots and generated run artifacts outside the source trees. The MoT fork retains the upstream PolyForm Noncommercial License.

Pin both repositories. The modified source commit is public on a dedicated branch. KNLP validates the exact seven-commit chain and key file hashes.
Run code and mechanics controls. Unit tests need no model. Real-model controls require the pinned GPT-2 and GPT-2-medium snapshots recorded in recipe.py.
Train and evaluate explicitly. Freeze the data manifest, run the diagnostic controls, train one directed checkpoint, then run the paired evaluation and four-arm attribution.
