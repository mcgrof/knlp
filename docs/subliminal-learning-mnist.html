What crossed the channel?

The assay follows the MNIST experiment in Subliminal Learning (Audio Summary). A teacher has ten digit outputs and three auxiliary outputs. Supervised digit training changes the shared trunk, even though the three auxiliary rows receive no digit supervision.

Teacher → student

Noise images, three outputs

The student sees 60,000 uniform-noise images and the teacher’s three auxiliary outputs. It sees neither MNIST images nor the ten digit outputs during this distillation. The shared trunk can change; the ten unused digit-head rows stay unchanged.

Outcome and controls

Measure gain over initialization

Evaluate MNIST digit accuracy afterward. Transfer gain is auxiliary-student accuracy minus that arm’s own untrained accuracy, W0. Pair seeds and compare shared initialization with independent initialization. Distillation from all 13 outputs is a separate utility control.

Scope: this is benign digit knowledge in small MLPs. It is not a test of harmful traits, language-model alignment, or a general defense. Changing the architecture changes both teacher and student, so the assay does not isolate the sending and receiving mechanisms.

A false null did not explain away real transfer

For bit-identical predictions and targets, the distillation gradient should be zero. The original composed KL path left gradients near 10−9 in FP32. Adam converted these into visible parameter movement; the behavior appeared on both AMD and NVIDIA GPUs. A near-zero loss was therefore not a sufficient null check.

The repaired first-order backward computes the explicit difference softmax(student) − softmax(target). Equal inputs cancel exactly. It does not bypass the optimizer. Across the 80-epoch null control, model parameters and optimizer moments stayed unchanged. Active teacher signals still learned, independent-initialization controls remained active, and the unused digit-head rows stayed fixed.

These controls changed the interpretation of the early architecture sweep. A lower auxiliary accuracy can reflect weaker or slower learning. The study required preserved teacher and all-output learning, not just a lower auxiliary endpoint.

What LayerRoPE changed in this assay

LayerRoPE (Audio Summary), by Shikhar Srivastava and Christopher Kanan, makes normalization gains depend on depth. In this MNIST adaptation, one shared gain vector and four learned schedule scalars generate the block input LayerNorm gains. The rotation acts on gains, not activations. Centering, bias, final normalization, and HC routing remain in place; no output normalization was added.

HC and this gain schedule act on different parts of the network and can be composed. That does not imply their learning effects add. This is a vision-style adaptation, not the paper’s full input/output RMSNorm language-model implementation.

Both LayerRoPE candidates preserved endpoint utility but failed to establish the required speed noninferiority. The upper interval bounds for the all-output epoch-to-95% ratio were 1.245 and 1.166, above the 1.10 limit. This is inconclusive speed preservation, not proof of a slowdown.

Frozen MNIST recipe and decision rule

Seeds 74001–74010; four width-256 blocks; five teacher epochs and 80 student epochs; batch 1024; Adam at 0.0003; FP32; no weight decay or compilation. Common linear weights, independent-control weights, fixed uniform noise, and named batch orders were paired across arms. Targets came directly from the frozen teacher; loss mode exact_cancel_v1.

LayerRoPE base 100, initial magnitude slope 0, rotation slope −0.5, and both log intercepts 0. Intercepts are explicit choices in this recipe. The screen required at least five points less transfer, an upper transfer interval below zero, utility lower bounds no worse than −2 points, and epoch-to-95% ratio upper bounds no greater than 1.10. Primary HC contrasts use 97.5% bootstrap intervals; supporting contrasts use 95%.

Conclusions

SUPPORTED

Subliminal digit transfer reproduces. HC can increase it in this assay. Real transfer survives a strict repair of the exact-null control.

NOT ESTABLISHED

No tested LayerRoPE or small-write candidate qualified as robust suppression with preserved learning. No general increase from mHC, or suppression from LayerRoPE, follows.

EXPERIMENTAL CONTROLS

Paired initializations, exact-null stationarity, direct-target distillation, unused-head checks, and utility/speed controls help distinguish an architectural effect from numerical drift or slower learning.

The negative findings are useful because they separate transfer, training speed, and numerical artifacts. The assay and its controls can be reused to evaluate other architectures without treating slower learning as successful suppression.

Reproduce the MNIST experiments

The aggregate route runs the reference transfer assay, historical cohorts, repaired residual-scale and null controls, and the four-arm LayerRoPE comparison. Each sub-study retains its own seeds, duration and loss convention. Use make defconfig-subliminal-mnist-smoke followed by make for a bounded CPU check on real MNIST.

make defconfig-subliminal-mnist
make

Install the dependencies in the reproduction guide. Run a separately named smoke preset first to check your environment. Configure data, output, checkpoints, device and time limits with make menuconfig; each run saves its effective settings and reports incomplete work.

Before training, qualification must verify exact shared-null stationarity, active teacher signals, active independent-initialization learning, finite gradients, unchanged unused digit-head rows, and teacher immutability. A failed qualification must stop the run.

Report accuracy and gain over each arm’s W0 separately, with paired seed intervals, teacher/all-output utility, and learning speed. To extend the study, change one factor at a time and keep the baseline controls and original configuration available. A new architecture or schedule is a new comparison, not a replacement for an unfavorable seed.
