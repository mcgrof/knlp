# Reproduce the validated CAS results

The public harness has three narrow profiles. `cas-paper` is the primary
five-patient H100 reproduction. `cas-training-spread-h100` reproduces the eight
patient-02 trainings used to measure determinism and seed variation.
`cas-paper-regime-a100` is the single-patient A100 control.

All profiles consume staged self-study parquets and LongHealth records. They do
not synthesize or fetch private inputs. Set `PAPER_DATA_DIR` to a directory
containing `<patient>.parquet`, and set `RECORDS_DIR` to a directory containing
matching `<patient>.txt` records.

## Five-patient H100 reproduction

This profile trains patients 01, 02, 03, 05, and 06 with document/20 KV tokens,
80 epochs, global batch 128, peak learning rate 0.1, a 200-step warmup from
0.002, and a 5,000-step linear-decay horizon. It evaluates every trained
cartridge for three Table-15 runs at both 2,048 and 8,192 completion tokens. It
also captures each complete document's exact KV and evaluates it through the
same cartridge path.

```sh
make defconfig-cas-paper
CUDA_VISIBLE_DEVICES=0 \
PAPER_DATA_DIR=/path/to/per_patient \
RECORDS_DIR=/path/to/records \
OUT_DIR=/path/to/cas-output \
CART_ROOT=/path/to/cartridges \
PYTHON=/path/to/python \
HF_HUB_OFFLINE=1 \
make
```

`OUT_DIR/paper_regime/` records the resolved training recipe, evaluation
protocol, input and output hashes, logs, cartridges, raw evaluation rows, and
completion markers. A completed patient can be resumed only when its training
recipe still matches. Evaluation settings are recorded separately and can be
extended without invalidating a completed training.

## Eight-training H100 seed spread

This profile launches two seed-42 determinism controls and seeds 43 through 48
on GPUs 0 through 7. It evaluates each resulting cartridge for three Table-15
runs in the same software session, verifies that the repeated seed produces
byte-identical artifacts, and writes the distinct-seed mean and sample standard
deviation to `OUT_DIR/training_spread/results.json`.

```sh
make defconfig-cas-training-spread-h100
PAPER_DATA_DIR=/path/to/per_patient \
RECORDS_DIR=/path/to/records \
OUT_DIR=/path/to/cas-output \
CART_ROOT=/path/to/cartridges \
PYTHON=/path/to/python \
HF_HUB_OFFLINE=1 \
make
```

This profile reproduces the eight new trainings on the CAS results page. The
page's common-session reference, half-learning-rate, prior-run, and A100 rows
are historical artifacts and are not regenerated by this profile.

## Single-patient A100 control

```sh
make defconfig-cas-paper-regime-a100
CUDA_VISIBLE_DEVICES=0 \
PAPER_DATA_DIR=/path/to/per_patient \
RECORDS_DIR=/path/to/records \
OUT_DIR=/path/to/cas-output \
CART_ROOT=/path/to/cartridges \
PYTHON=/path/to/python \
HF_HUB_OFFLINE=1 \
make
```

The A100 profile disables compiled FlexAttention because the CUDA 13 stack used
for the measured control could not lower that kernel reliably. The eager path is
slower but preserves the training recipe. An out-of-memory error fails the run;
do not silently lower the batch size and learning rate.
