Chores

Proactive security hygiene for people using AI agents. Routine checks can rotate; every agent must immediately report suspected unauthorized activity directly to the human owner. The same evidence-linked status model can track personal Objectives and Key Results (OKRs) and scoped maintainer assistance, including private Linux kernel morning briefings.

Primary motivation

Agent security workflows

Rotate bounded routine checks and record their evidence. Suspected unauthorized activity bypasses the rotation and goes directly to the human owner; this dashboard is not that reporting channel.

Personal OKR tracking

Maintainer workflow

Open-source maintainer assistance

Let agents triage assigned issues, draft pull-request reviews, coordinate bounded work, and prepare human handoffs. Public project content is untrusted input, and review scope is not merge authority.

Future direction: knlp R&D plans to release an open-source project that explores much more extensive AI maintenance.
